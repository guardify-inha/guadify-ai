# 2단계 심층 연구 요약: 하이브리드 검색 전략

## 2.1 Graph RAG 검색 전략 연구

### 주요 검색 전략 유형

1. **직접 벡터 검색 (Direct Vector Search)**
   - 질의 임베딩과 노드 임베딩 간 코사인 유사도 계산
   - 가장 기본적이고 빠른 방법
   - 현재 1단계에서 준비 완료

2. **그래프 순회 (Graph Traversal)**
   - 시작 노드에서 관계를 따라 다른 노드 탐색
   - 예: 조 -> 항 -> 호 순회
   - 법률 구조의 계층적 특성 활용

3. **관계 가중치 (Relationship Weighting)**
   - 관계 유형에 따라 다른 가중치 부여
   - 예: HAS_VIOLATION 관계는 높은 가중치
   - 관련성을 반영한 점수 계산

4. **다단계 탐색 (Multi-hop Search)**
   - 여러 관계를 거쳐간 노드까지 탐색
   - 예: 조 -> 위반사례 -> 수정본 -> 다른 위반사례
   - 간접적 관련성 발견

5. **역방향 검색 (Reverse Search)**
   - 위반사례에서 역으로 조/항/호 탐색
   - "이 위반사례가 어떤 조항을 위반했는가?" 질의에 유용

## 2.2 한국어 법률 문서 검색 특성

### 법률 문서의 구조적 특성
- 계층적 구조: 법률 -> 조 -> 항 -> 호
- 명확한 관계: HAS_HANG, HAS_HO
- 위반사례 연결: HAS_VIOLATION으로 직접 연결

### 한국어 처리 고려사항
- 형태소 분석 필요성 (키워드 추출)
- 법률 용어의 특수성 (전문 용어 처리)
- 동의어 및 유사어 처리 (예: "책임" = "면책"의 반대 개념)

## 2.3 하이브리드 전략 설계 원칙

### 3가지 검색 방법 결합

1. **의미적 유사도 검색 (Semantic Search)**
   - 질의와 법률 조항(조/항/호) 임베딩 간 유사도
   - 가중치: 0.5 (50%)

2. **키워드 매칭 검색 (Keyword Matching)**
   - 질의에서 핵심 키워드 추출 및 매칭
   - 법률 용어 특화 처리
   - 가중치: 0.3 (30%)

3. **그래프 구조 점수 (Graph Structure Score)**
   - 그래프 경로를 통한 관련성 계산
   - 위반사례와의 연결 강도
   - 가중치: 0.2 (20%)

### 점수 계산 공식

```
최종 점수 = (의미적 유사도 × 0.5) + (키워드 점수 × 0.3) + (그래프 점수 × 0.2)
```

## 2.4 구현 전략

### 단계별 검색 프로세스

1. **1단계: 의미적 검색**
   - 질의를 임베딩하여 모든 조/항/호와 비교
   - Top-K 후보 선별 (예: 상위 20개)

2. **2단계: 키워드 필터링**
   - 후보 중에서 키워드 매칭 강화
   - 법률 용어 사전 활용

3. **3단계: 그래프 보강**
   - 선별된 후보의 그래프 이웃 탐색
   - 위반사례와의 연결 확인

4. **4단계: 재순위화**
   - 통합 점수 계산
   - 최종 Top-N 반환 (예: 상위 5개)
