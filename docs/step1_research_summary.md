# 1단계 심층 연구 요약

## 1.1 한국어 법률 문서 임베딩 모델 연구

### 현재 상태
- 사용 중인 모델: `paraphrase-multilingual-MiniLM-L12-v2`
- 특징: 범용 다국어 모델, 법률 도메인 특화 없음

### 권장 모델 후보
1. **paraphrase-multilingual-mpnet-base-v2**
   - 장점: 더 큰 모델, 성능 우수, 다국어 지원
   - 단점: 모델 크기 커서 로딩 시간 증가

2. **jhgan/ko-sroberta-multitask**
   - 장점: 한국어 특화, 여러 태스크 학습
   - 단점: 법률 도메인 특화 여부 불확실

3. **현재 모델 유지**
   - 장점: 이미 동작 중, 추가 변경 없음
   - 단점: 법률 도메인 성능 제한

### 권장사항
초기 구현에서는 **paraphrase-multilingual-mpnet-base-v2**로 전환 후 평가

## 1.2 Neo4j 벡터 저장 방법

### 현재 구조
- 노드 프로퍼티에 배열로 저장: `embedding: [float, float, ...]`
- Python에서 코사인 유사도 계산

### Neo4j 5.x 벡터 인덱스
- 벡터 인덱스 지원 여부 확인 필요
- 프로퍼티 배열 방식이 현재 프로젝트에 적합할 수 있음

### 권장사항
현재 프로퍼티 배열 방식 유지 (단순성, 호환성)
