# 3단계 심층 연구 요약: LLM-as-Judge 및 HyDE 기법

## 3.1 LLM-as-Judge 패턴

### 개념

- LLM을 판단자(Judge)로 활용하여 질의와 후보 조항 간의 관련성/위반 가능성을 평가
- 구조화된 평가 기준을 통해 일관된 판단 수행

### 적용 방법

1. **평가 기준 정의**

   - 질의의 핵심 내용 추출
   - 후보 조항의 위반 가능성 판단 (0.0-1.0)
   - 구체적인 근거 제공

2. **구조화된 프롬프트**

   - 시스템 프롬프트: 판단 기준 명시
   - 사용자 프롬프트: 질의 + 후보 조항 제공
   - JSON 형식 응답 (점수, 근거, 신뢰도)

3. **배치 평가**
   - 여러 후보를 동시에 평가하여 효율성 향상
   - 상대적 비교를 통한 순위화

## 3.2 HyDE 기법

### 개념

- 질의에 대한 "가상의 답변 문서"를 생성
- 이 가상 문서를 임베딩하여 검색 (더 나은 검색 정확도)

### 적용 방법

1. **가상 문서 생성**

   - 질의: "회사는 책임을 지지 않는다"
   - 가상 문서: "이 약관은 면책 조항으로, 제7조에 위반될 가능성이 높습니다..."

2. **2단계 검색**

   - 1단계: 질의 임베딩으로 초기 후보 검색
   - 2단계: 가상 문서 임베딩으로 재검색 및 보강

3. **하이브리드 결합**
   - 질의 임베딩 검색 결과와 가상 문서 임베딩 검색 결과 통합

## 3.3 통합 전략

### 프로세스

1. 하이브리드 검색으로 후보 선별 (2단계 결과 활용)
2. HyDE로 가상 문서 생성 및 추가 후보 확보
3. LLM-as-Judge로 최종 후보들 평가
4. 위반 가능성 점수 및 순위 반환

### 장점

- 검색 범위 확대 (HyDE)
- 정확한 위반 판단 (LLM-as-Judge)
- "위반 여부" 중심 판단 가능
