# 2단계 실행 요약: 하이브리드 검색 전략 구현

## 구현 완료 사항

### 1. HybridRetriever 클래스 생성
- 위치: `retriever/hybrid_retriever.py`
- 기능: 3가지 검색 방법을 결합한 하이브리드 검색

### 2. 하이브리드 검색 프로세스

#### 단계별 처리:
1. **의미적 검색** (50% 가중치)
   - 질의 임베딩과 법률 조항 임베딩 비교
   - Top-20 후보 선별

2. **키워드 매칭** (30% 가중치)
   - 질의에서 핵심 키워드 추출
   - 법률 용어 사전 활용
   - 후보 조항과 키워드 매칭 점수 계산

3. **그래프 구조 점수** (20% 가중치)
   - 위반사례와의 연결 강도 확인
   - 위반사례 개수에 따른 점수 부여 (로그 스케일)

4. **통합 점수 및 재순위화**
   - 최종 점수 = (의미적 × 0.5) + (키워드 × 0.3) + (그래프 × 0.2)
   - 최종 Top-K 반환

### 3. 테스트 스크립트
- 위치: `retriever/test_hybrid_retriever.py`
- 5개 테스트 케이스 포함

- 개선이 필요하면 → 하이퍼파라미터 튜닝 또는 로직 개선
