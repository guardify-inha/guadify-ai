# 종합 테스트 결과 확인 가이드

## 📊 결과 파일 위치

테스트 결과는 다음 두 가지 형식으로 저장되어 있습니다:

1. **CSV 파일** (Excel이나 스프레드시트에서 열 수 있음)

   - 경로: `docs/comprehensive_test_results.csv`
   - 120개 테스트 케이스의 상세 결과 포함

2. **JSON 파일** (프로그래밍 분석용)
   - 경로: `docs/comprehensive_test_results.json`
   - 통계 및 상세 결과 포함

## 📋 결과 파일 구조

### CSV 파일 컬럼

- **번호**: 테스트 케이스 번호 (1-120)
- **테스트\_문장**: 테스트한 약관 조항 문장
- **예상\_결과**: 기대한 조항 (제6조~제14조)
- **실제\_결과**: 시스템이 예측한 조항
- **예측*성공*여부**: "성공" 또는 "실패"
- **통합\_점수**: 하이브리드 검색 + LLM 점수 (0.0-1.0)
- **LLM*위반*가능성**: LLM이 판단한 위반 가능성 (0.0-1.0)

### 결과 확인 방법

#### 1. Excel/스프레드시트에서 열기

```bash
# macOS
open docs/comprehensive_test_results.csv

# 또는 직접 파일 탐색기에서 열기
```

#### 2. 터미널에서 확인

```bash
# 상위 20개 결과 보기
head -20 docs/comprehensive_test_results.csv

# 성공한 케이스만 보기
grep "성공" docs/comprehensive_test_results.csv

# 실패한 케이스만 보기
grep "실패" docs/comprehensive_test_results.csv
```

#### 3. Python으로 분석

```python
import pandas as pd
df = pd.read_csv('docs/comprehensive_test_results.csv')

# 성공률 확인
print(f"전체 정확도: {df['예측_성공_여부'].value_counts()}")

# 조항별 정확도
for article in df['예상_결과'].unique():
    article_df = df[df['예상_결과'] == article]
    accuracy = (article_df['예측_성공_여부'] == '성공').sum() / len(article_df) * 100
    print(f"{article}: {accuracy:.1f}%")
```
