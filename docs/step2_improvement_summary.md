# 2단계 개선 요약: 하이브리드 검색 향상

## 개선 배경

3단계 테스트에서 하이브리드 검색 결과가 잘못된 조항을 상위에 랭킹하는 문제가 발견되었습니다.
예: "회사는 어떠한 피해배상도 하지않는다" → 제7조 기대, 제11조 선택

## 개선 내용

### 1. 조항별 키워드/패턴 통합
- `judge_clause.py`의 `ARTICLE_PATTERNS`를 하이브리드 검색에 통합
- 각 조항별 특성에 맞는 키워드와 정규식 패턴 활용

### 2. 키워드 매칭 로직 개선
- **조항별 키워드 매칭**: 질의와 조항 내용 모두에서 키워드 매칭 확인
- **패턴 매칭 추가**: 정규식 패턴으로 더 정확한 조항 식별
- **가중치 적용**: 긴 키워드일수록 높은 가중치, 패턴 매칭 시 보너스 점수

### 3. 점수 계산 방식 변경
- **키워드 점수 가중치 증가**: 30% → 40%
- **의미적 유사도 가중치 감소**: 50% → 40%
- **패턴 매칭 보너스**: 패턴 매칭 시 추가 0.1점 부여

### 4. 검색 범위 확대
- 의미적 검색 후보 수: 20개 → 30개
- 더 넓은 후보군에서 키워드/패턴 매칭으로 정확한 조항 선별

## 개선 효과

### 정확도 변화
- **이전**: 20% (1/5)
- **개선 후**: 80% (4/5)

### 성공 사례
1. **제7조 (면책 조항)**: "회사는 어떠한 피해배상도 하지않는다"
   - "피해배상", "책임", "배상" 키워드 및 패턴 매칭으로 정확히 식별
   
2. **제9조 (해지 권한 제한)**: "계약을 해지할 수 없습니다"
   - "해지" 키워드 및 패턴 매칭으로 정확히 식별
   
3. **제6조 (일반원칙)**: "고객에게 부당하게 불리한 조항"
   - "부당", "불리" 키워드로 정확히 식별
   
4. **제10조 (일방적 변경)**: "회사가 일방적으로 계약을 변경할 수 있습니다"
   - "일방적", "변경" 키워드 및 패턴 매칭으로 정확히 식별

### 개선 필요 사항
- **제8조 (과중한 손해배상)**: "과도한 손해배상금을 부담해야 합니다"
  - 제7조 패턴과도 매칭되어 선택됨
  - 제8조 패턴 강화 필요 (예: "과도", "과중", "손해배상금" 키워드 우선순위)
